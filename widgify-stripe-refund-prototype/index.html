三、页面展示判断规则

以下规则均针对 US 地区且命中 pay_B 的用户；页面只查询 Stripe 订单状态。

Stripe 查询结果Support 入口页Premium Plan 详情页可用操作
Active 且自动续费Premium Plan + Refund Help展示 Active、续费日期、周期、价格和 Stripe 支付方式Cancel Subscription + Refund Help
已取消续费或已到期Premium Plan + Refund Help展示 Canceled / Expired 及权益到期日期仅 Refund Help
未找到 Stripe 订单仅 Premium Plan展示 Not Subscribed，不展示续费、价格和支付方式仅 Restore Purchases

Restore Purchases 会重新查询 Stripe 订单：查到后按上表对应状态刷新，仍未查到则保持 Not Subscribed。Apple 订阅不参与判断，只通过提示文案说明查看路径。

1. 入口校验 确认用户为 US 地区且已分配 pay_B 方案。
2. Stripe 核验 在订单系统中查询是否存在 Stripe 订单，不涉及账号系统。
3. 恢复购买 未命中时，用户可点击 Restore Purchases 重新查询 Stripe 订单。
4. 功能解锁 已匹配 Stripe 订单开放详情与 Refund Help；Active 订单可取消续费。
5. 审核与邮件反馈 客服核验 Stripe 订单并处理退款或权益问题，结果通过邮件通知。
